### RDS 创建命令（已实测，可直接粘贴）

```powershell
D:\ICT_creating_match\provision.cmd create rds `
  --name codecraft-db `
  --arg flavor_ref=rds.mysql.n1.large.2 `
  --arg datastore.type=MySQL --arg datastore.version=5.7 `
  --arg availability_zone=cn-north-4a `
  --arg volume.type=CLOUDSSD --arg volume.size=40 `
  --arg region=cn-north-4 `
  --arg vpc_id=985b5715-d1ea-488c-8ae1-dfba7efa0d61 `
  --arg subnet_id=51cfc60e-c827-4216-83ee-68ff8bfa3176 `
  --arg security_group_id=75ca6cb1-bf51-47f6-a7ed-73fdbd77b10e `
  --dry-run
```

- 最低在售规格 **2vCPU/4GB**（cn-north-4 没有更小的）
- `--dry-run` 只预览；确认后加 `--yes` 才真创建（**从创建那刻开始计费**）
- 创建一般 5–15 分钟，用 `provision.cmd wait rds --id <ID> --timeout 1800` 等就绪

## 9. 已踩的坑 + 固定规则（12 条，别再踩）

| # | 规则 |
|---|---|
| 1 | **技能 zip 的顶层必须是技能文件夹本身**，且文件夹名 == SKILL.md 的 `name`。不要把 `.codeartsdoer/` 一起压 |
| 2 | 技能包体积上限 **5MB**；导入前跑 `check-skill.cmd` 或 `validate_skill.py` |
| 3 | **`.cmd` 文件必须纯 ASCII**，中文注释会被 GBK 解析成乱码甚至当命令执行 |
| 4 | cmd 里 `"D:\path\"` 末尾反斜杠会被 `\"` 转义吞掉 → 传路径前去掉尾斜杠 |
| 5 | **`ListFlavors` 必须加 `--cli-read-timeout=120`**，返回值 139KB，默认超时必失败（脚本已默认注入） |
| 6 | 安全组是**项目级**（Neutron），`vpc_id=None` 是**正常**的。判定标准是「新建时间晚于 VPC + 规则符合预期」，不是看 vpc_id |
| 7 | 旧 `Sys-default` 的 `vpc_id="default"` 是伪 VPC 标记 → **不能用** |
| 8 | 安全组默认规则**只允许同 SG 内互通 + 出站**，没有任何公网入站 → ECS 要手工加 22/80/443 |
| 9 | **ECS 和 RDS 必须挂同一个安全组、同一 VPC、同一子网**，否则内网不通 |
| 10 | **3306 / 6379 绝不对公网开放**；22 端口只放自己 IP |
| 11 | **不要买域名**：大陆节点备案要 1–3 周。用 `http://<公网IP>/` |
| 12 | 云资源要**买到 12 月中旬**（不是 1 个月），否则评审时链接失效；资源打 `Project=CodeCraft` 标签 |
