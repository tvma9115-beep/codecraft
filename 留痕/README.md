# 留痕索引

> 本目录保存**华为云 CodeArts 智能体 / Skill** 的使用证据，用于申报材料的「工具链使用价值（≤1000 字）」。
>
> ⚠️ **禁止提交任何密钥**（AK/SK、API Key、密码）。截图前请打码。

## 五个环节（对应申报模板的五个小标题）

| 目录 | 对应环节 | 记什么 |
|---|---|---|
| `01-需求理解/` | 需求理解 | 把「积木工具没有逻辑错误反馈」梳理成需求的对话截图 |
| `02-代码生成/` | 代码生成 | 生成 RDS 建表 SQL、Docker Compose、worker 消费逻辑的截图 |
| `03-项目构建/` | 项目构建 | 目录从空到成型的过程、依赖安装、编译通过 |
| `04-问题修复/` | 问题修复 | **最有价值**：沙箱超时不死、source map 行号偏移的排查过程 |
| `05-部署上线/` | 部署上线 | 本地跑通 → ECS 公网可访问的截图对比 |

## 每次留痕的记录格式

每个证据建一个 `<日期>-<简述>.md`，内容：

```markdown
# <标题>

- **日期**：2026-10-xx
- **环节**：代码生成
- **工具**：CodeArts 代码智能体 / Skill `<名称>`
- **输入**：（粘贴当时的 prompt）
- **输出摘要**：（关键结果，不要贴完整长输出）
- **人工修改**：（哪些地方是我们改的，改了为什么）
- **截图**：`screenshots/<文件名>.png`
- **价值对照**：不用工具时预计 ___，用了之后 ___（这是 1000 字里最有说服力的部分）
```
