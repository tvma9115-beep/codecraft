# 排错手册

> **总原则：不要反复重试。** 每次失败先定位是哪一层的问题，再动手。
> 排查顺序永远是从下往上：**凭证 → 区域 → 网络 → 配额 → 参数**。

---

## 第 0 步：先跑体检

```bash
python scripts/doctor.py
```

90% 的初级问题（AK/SK 没设、hcloud 没装、区域没配）在这里就能看出来。

---

## 一、认证与权限类

### `401` / `Unauthorized` / `APIGW.0301`

| 可能原因 | 怎么确认 | 怎么解决 |
|---|---|---|
| AK/SK 写错或贴截断 | 打印 AK 末四位对比 | 重新复制，注意前后不要有空格 |
| AK/SK 已被删除/禁用 | 控制台 → 我的凭证 → 访问密钥 | 新建一对，更新环境变量 |
| 用的是国际站密钥访问中国站 | 看账号所在站点 | 密钥与站点必须对应 |
| **账号未实名认证** | 控制台 → 账号中心 | **实名后才允许购买付费资源** |

### `403` / `Forbidden` / `APIGW.0302`

| 可能原因 | 怎么解决 |
|---|---|
| 子账号缺少对应服务的权限 | 用主账号操作，或给子账号授 `RDS FullAccess` / `DCS FullAccess` |
| 服务未开通 | 控制台进入一次该服务页面，按提示开通 |

### `hcloud` 提示未配置认证信息

```bash
hcloud configure list      # 看现有配置
hcloud configure set       # 交互式配置 AK/SK/区域
```

本技能的脚本依赖**环境变量**注入 AK/SK。如果 `hcloud configure` 里也配了，两者都行，**环境变量优先**。

## 二、区域与网络类

### `VPC not found` / `subnet not found` / `Invalid VPC ID`

**最常见的原因是区域选错。** VPC ID 是区域级资源，北京的 VPC ID 在华南查不到。

```bash
echo $env:HW_REGION      # PowerShell
hcloud RDS ListInstances --cli-region=cn-north-4   # 显式指定区域再试
```

确认三件事一致：**ECS 在哪、RDS 在哪、`HW_REGION` 是什么**。

### 实例创建成功但 ECS 连不上

按这个顺序查，**不要跳步**：

| 顺序 | 检查项 | 怎么查 |
|---|---|---|
| 1 | 是否同一 **VPC** | 控制台看三个实例的 VPC ID |
| 2 | 是否同一**子网**（或子网间可达） | VPC 详情页看路由 |
| 3 | 是否用了**内网地址**（不是公网） | 连接串里的 IP 应该是 192.168.x.x 这类 |
| 4 | RDS/DCS 侧**白名单**是否包含 ECS 内网 IP | 实例详情页 → 白名单 |
| 5 | **安全组**是否互相放通 | 注意：跨安全组时要两边都配 |
| 6 | 从 ECS 上 `ping` 网关 | `ping 192.168.0.1` 验证基础网络 |

> **在你自己电脑上直连一定失败** —— RDS/DCS 没有公网地址。必须在 ECS 上测。

### `timeout` / 连接超时

- 先确认实例状态是 `ACTIVE`（`provision.py show --id <ID>`）
- 再确认安全组不是全封
- 最后才怀疑网络本身

## 三、配额与资源类

### `QuotaExceeded` / `配额不足` / `ResourceInsufficient`

| 原因 | 解决 |
|---|---|
| 该区域实例数到上限 | 控制台 → 资源 → 我的配额，提交提额工单（**要等，别拖到 11 月**） |
| 该规格在当前可用区售罄 | 换可用区（`cn-north-4a` → `4b`） |
| 磁盘/内存券余额不足 | 账户充值或换更小规格 |

### `Instance name already exists` / 名称冲突

实例名在同一账号内通常要求唯一。换个名字，别删已有实例。

## 四、参数类（最容易被误判成"系统坏了"）

### `Invalid parameter` / `缺少必填参数` / `Unknown parameter`

这不是故障，是**参数名对不上**。

```bash
python scripts/provision.py probe rds CreateInstance
```

**拿 probe 输出里的真实字段名重新拼命令，不要凭记忆改。**
华为云不同服务、不同 API 版本的字段名差异很大，例如"规格"可能叫 `flavor`、`flavor_ref` 或 `spec_code`。

### 创建返回成功但状态一直是 `CREATING`

正常。RDS 创建通常要 **5–15 分钟**。

```bash
python scripts/provision.py wait rds --id <实例ID> --timeout 1800
```

超过 30 分钟没变化 → 去控制台看实例详情里的任务记录，可能已失败但没抛错。

### `provision.py list` 输出不是 JSON

华为云 CLI 偶尔在 JSON 前后夹带提示行。脚本已经做了容错截取；如果仍然失败，加 `--json` 看原始返回，或直接把输出贴出来人工判断。

## 五、KooCLI 自身问题

| 现象 | 解决 |
|---|---|
| `hcloud` 命令不存在 | 没装或没加进 PATH。装完**重开终端** |
| `hcloud version` 报错 | 安装不完整，重装 |
| 提示服务名不对 | `hcloud --help` 列出全部服务名，确认是 `RDS` / `DCS` |
| 动作名不对 | `hcloud RDS --help` 列出该服务全部动作 |
| 输出编码乱码 | Windows 下常见。设 `chcp 65001` 或改用 PowerShell 7 |
| **`[USE_ERROR]调用API超时`** | **默认 readTimeout 太小**。加 `--cli-read-timeout=120`。`ListFlavors` 返回约 139KB，实测需要 10 秒以上，不加这个参数必失败 |
| `记录日志失败:访问被拒绝` | KooCLI 想把日志写进一个没权限的目录。**不影响 API 调用**，可忽略 |
| hcloud 不在 PATH 里（绿色版/解压版） | 本技能脚本会自动在常见安装目录里找；也可设 `HCLOUD_BIN=<完整路径>` |

### 已实测的环境事实（2026-10，cn-north-4）

| 项 | 值 |
|---|---|
| hcloud 位置 | `D:\huaweicloud-cli-windows-amd64\hcloud.exe`（**不在 PATH**） |
| KooCLI 版本 | 7.3.12 |
| 凭据位置 | `C:\Users\<用户>\.hcloud\config.json`（**加密存储，无需环境变量**） |
| 可用区域 | **仅 cn-north-4 可达**，cn-east-3 等 endpoint 网络不可达 |
| RDS 最低在售规格 | 2vCPU/4GB，如 `rds.mysql.n1.large.2`（single） |
| 默认安全组 | `default`（存在） |
| VPC | **0 个 —— 需要先创建 VPC 和子网** |

## 六、安全红线（违反任一条都会影响比赛评分）

| 红线 | 说明 |
|---|---|
| **AK/SK 不能进 Git** | 一旦推上去，立刻去控制台**删除重建**。改历史不够，密钥已泄漏 |
| **3306 / 6379 不对公网开放** | RDS/DCS 走 VPC 内网。开放公网是安全问题，答辩会被问 |
| **不上 `0.0.0.0/0` 白名单** | 只放通 ECS 内网 IP 或子网段 |
| **SSH 22 端口限制来源 IP** | 别对全网开放 |
| 实例加 `Project` 标签 | 便于对账与按时清理，避免欠费 |

## 七、还是解决不了怎么办

按这个顺序升级，**不要越级**：

1. 贴出**完整命令 + 完整错误输出**（脱敏 AK/SK），先自查一遍是否参数名问题
2. 跑 `probe` 确认接口签名
3. 去控制台用**图形界面**做同样的操作——如果界面能成、命令行不能成，多半是参数名问题
4. 提**工单**（控制台 → 工单管理），附上：区域、服务、完整报错、时间点
5. 把整个过程记进 `留痕/踩坑日记.md` —— **这是材料里"问题修复"环节的真实素材**
